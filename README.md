# ⚖️️ Inanitas Abogados | Plataforma Web Corporativa

> *"Estrategia en la derrota. La certeza jurídica que su tranquilidad necesita."*

¡Bienvenido/a al repositorio de **Inanitas Abogados**! 🏛️ 
Esta es la página web corporativa de una firma legal ficticia especializada en la **clausura estratégica de litigios** (allanamientos incondicionales, resolución de proindivisos tóxicos y reestructuraciones corporativas). 

El proyecto destaca por su diseño institucional y elegante en 🌙 **Dark Mode**, garantizando una experiencia inmersiva, accesible y 📱 **100% responsiva** para cualquier tamaño de pantalla.

## 🤖 Metodología: La magia del *Vibecoding*

La particularidad técnica más destacada de este repositorio es que la **totalidad del código** (HTML5, CSS3 y JavaScript) ha sido construida íntegramente mediante **✨ Vibecoding ✨**.

El desarrollo se ha llevado a cabo utilizando **Gemini Pro 3.1** como modelo de inteligencia artificial principal (IA). En lugar de la escritura manual de código tradicional, el proyecto ha cobrado vida estructurando directrices, iterando sobre diseños y refinando el comportamiento interactivo exclusivamente a través de **lenguaje natural**. 

**¿Qué destrezas técnicas incluye?** 🪄
* 🏗️ **Arquitectura semántica** multipágina bien estructurada.
* 🎨 **Estilos modernos:** Uso de CSS Grid, Flexbox, variables CSS y Media Queries para un diseño *Mobile First*.
* ⚡ **Lógica interactiva en Vanilla JS:** Menú hamburguesa desplegable y simulación de envío de formularios.
* 🎭 **Branding integrado:** Recursos gráficos y paleta de colores institucionales (tonos carbón y bronce).

## 📂 Estructura del Proyecto

El proyecto consta de una arquitectura limpia de *frontend* estático:

* 🏠 `index.html` - Página de inicio (Sección *Hero* y manifiesto corporativo).
* 🏛️ `bufete.html` - Historia, misión, visión, valores y ventaja competitiva.
* 💼 `practica.html` - Detalle de las áreas de actuación y tabla estructurada de honorarios fijos.
* ✉️ `contacto.html` - Formulario de evaluación de viabilidad con validación simulada.
* 🖌️ `style.css` - Hoja de estilos global y centralizada.
* 🖼️ `/assets/` - Directorio de recursos estáticos (logotipos, iconos y fondos).

## 🚀 Despliegue

La web está diseñada para ser ligera y alojarse de forma estática. 

* 💻 **Entorno Local:** Puedes clonar el repositorio y visualizarlo directamente abriendo cualquier archivo `.html` en tu navegador, o sirviéndolo a través de la extensión *Live Server* en VS Code.
* 🌐 **Producción:** El proyecto está configurado para desplegarse de manera automática y continua desde la rama principal (`main`) utilizando **GitHub Pages**. (https://kaehl1.github.io/inanitas-web/index.html)
